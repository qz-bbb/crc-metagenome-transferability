# v2.0.0 — R2 code and exact ENA metadata snapshots

This release adds the reviewed `r2_reproducibility/` workflow and the separately attributed `source_snapshots/ena_20261010/` reports. It preserves the v1.0.1 baseline files and existing tags. No scientific model, feature-selection rule, effect definition or result was changed for publication.

## Added reproducibility routes

- Portable common-MetaPhlAn4 training/locking and external-cohort prediction/evaluation, nested LOSO, fixed learners, rule ablation, identity sensitivity and effect-definition decomposition.
- Explicit historical-full, accession enrichment, identity audit and sparsity intermediate generators, plus result-to-script and source/dependency inventories.
- Commit-pinned MicrobiomeHD recovery routes; the two third-party tables are deliberately not redistributed.
- Exact ENA snapshots for PRJNA447983 and PRJEB27928 from 2026-10-10. The original retrieval provenance is retained separately from later recovery receipts. Import these snapshots using the strict local-import command in `r2_reproducibility/RELEASE_PREPARATION.md`.

## Actual verification and limits

The source-recovery checkpoint passed 138 tests in seven suites using the recorded existing Python 3.12.10 runtime. Twelve historical output tables were reproduced (ten byte-identical, two gzip tables identical after decompression), four identity tables were byte-identical, and three existing downstream consumer tables were byte-identical. Earlier generator checks also reproduced eight sparsity tables and nine downstream definition tables. The included dated reports give the exact scope and hashes; these are not new scientific results.

The preceding isolated-environment checkpoint passed 68 tests and replayed eleven rule selections and 182 saved-prediction AUROC/AP point estimates. That environment was populated from locally installed distributions, not a successful fresh network package resolution. All model fits and historical 2,000-resample intervals were not rerun during release preparation. The broad `identity_audit_summary.json` remains an explicitly frozen aggregate checkpoint, not newly generated by the narrow recovery helper. A complete one-command reconstruction of every legacy artifact is not claimed.

Publishing these materials neither proves ICP superiority nor constitutes author scientific sign-off, independent human review, raw-read reprocessing or clinical validation. No journal submission is performed by this release.
