# Input and output contract

All path values resolve against the JSON config location. Local configs/inputs/outputs stay outside the repository. No import performs data reads, downloads, fitting or writing.

| Config key | Meaning | Used by |
| --- | --- | --- |
| source_root | Verified MP4 source directory containing extracted/metadata and extracted/metaphlan4_profiles | audit,select,fit-model,full assemble,external routes |
| training_manifest | Original-order nine-study selection generated by ../r2_reproducibility/portable.py mp4-audit | training routes,full assemble |
| state | Receipted select output state.joblib | fit-model,assemble |
| model_dirs | Exactly18 distinct,receipted fit-model directories with the same state hash | assemble |
| model_bundle | Receipted full assemble output bundle.joblib | external-predict,directions;optional lock crosscheck at external-evaluate |
| blind_dirs | Previously completed prediction directories for cross-cohort checks;all six are mandatory before reading external clinical outcomes | external routes |
| predictions,metadata | Saved labelled probability grid and aligned evaluation metadata | evaluate,point-replay |
| study_names | Sorted nine unique study names from audit study_inventory.tsv | evaluate,summary-internal |
| evaluation_dirs | Complete nine internal or six external fixed2000-draw evaluation directories | summaries |
| state_dirs | One full-training or all nine fold select output directories | membership |
| historical_directions | Existing species_replication_all800.tsv from the same-cohort baseline multi-replicate route | directions |
| baseline_predictions | Optional historical six-model blind grid from baseline multi-predict | external-predict replay |
| output_root | Fresh action destination,outside code and every configured input tree | every action |

Training manifest fields: sample_uid,sample_id,subject_id,study_name,source_stem,study_condition. sample_uid and within-study subjects are unique; labels are CRC/control. Every deposited source metadata/profile pair is byte-verified against the existing recovery contract. Finite nonnegative species abundance is in percentages; absent species rows are zero-filled only among these verified same-source profiles. Source profiles preserve full taxon string IDs and requested sample order. Duplicate original TSV headers are rejected before pandas can mangle them. All numeric reads use float_precision=round_trip and writes use17 significant digits.

Internal labelled predictions require sample_uid,held_out_study,panel,classifier,k,y,probability_crc. Evaluation metadata require sample_uid,study_name,study_condition. Every sample has the entire nine-panel/two-learner grid,one positive integer k per study,correct joined labels and finite probabilities in[0,1]. Blind external predictions require sample_id,panel,classifier,k,probability_crc;source metadata use Sample Source ID and Study condition. Adenomas are retained in blind source grids and excluded only during labelled evaluation.

State and model artifacts are trusted local generated joblib files; do not load untrusted downloaded pickle/joblib files. selection state identity includes training input coordinates/labels/studies/order,config,retained universe,pseudocount,memberships and package versions. The CLI additionally verifies generated artifact receipts,complete grids,one full model lock across all blind cohorts,and changed input hashes before PASS. Receipts contain local absolute provenance paths for internal audit and must be excluded from public sample-data exports.

Each action creates a fresh directory. receipt.json records action,status,input/output SHA256,packages and relevant scope/seed/context. No failed action earns a PASS receipt. Initial protected inputs are hashed and checked again before sealing; this detects drift but is not an atomic snapshot or a lock against concurrent writers.

scores.npz stores exact point/bootstrap arrays; evaluation.json records ordered model_keys and actual index_hash. External evaluation receipt.json also retains cohort, model_bundle_sha256 and blind_set_sha256 derived from the verified complete blind set, even when model_bundle is omitted. The blind-set fingerprint hashes a canonical sorted cohort-to-receipt-SHA256 map together with the shared model SHA256; input directory order does not affect it. External summaries require matching nonempty lowercase SHA256 identities across all six receipts and receipt cohort equal to metric scope, then preserve the shared identities in their own receipt. Legacy external evaluation receipts without those identities cannot be silently combined.

CLI summaries reject smoke arrays instead of representing them as fixed2000 intervals. Primitive evaluation APIs retain a smaller n_boot option solely for synthetic tests;scientific CLI commands expose no such override.

Unsupported legacy artifacts are manuscript files,reviewer responses,cover letters,earlier package/checkpoint byte formats,and the original chronology of cross-run local receipts. Numerical primitives and saved-probability replay are supported; historical C receipt names and numerical replay evidence are not manufactured. Figure 8 and S4 prediction-sheet TSV export are provided separately by [report_extension](../report_extension/README.md); complete historical workbook reconstruction is outside this module. Source expected values and inclusion of code do not assert fresh full model fitting.
